# Proyecto de Programación

Proyecto inicial en Java con Maven.

## Requisitos

- JDK 17 o superior
- Maven 3.8 o superior

## Ejecutar

Desde la raíz del proyecto:

```bash
mvn compile
mvn exec:java
```

La aplicación inicial imprime un mensaje de bienvenida. El código fuente está en `src/main/java`.
